# 대화창의 차트 보조 데이터

종목·진입·차트 분석에는 결론만 쓰지 말고 근거 수치를 대화창에서 바로 읽을 수 있게 표시한다. 기본은 짧은 결론과 Markdown 표다. 사용자가 요구한 지표를 우선하며 단순 화면 이동에는 전체 표를 붙이지 않는다.

## 데이터 확보

- 성공한 `inspect`의 실제 snapshot을 우선한다. `status: done`이 없는 화면 전환을 완료됐다고 말하지 않는다.
- 화면 응답이 없으면 기존 서버의 `/api/lookup?code=SYMBOL`에서 한 번 확보한 frame으로 보조 데이터를 표시할 수 있다. 이는 서버 자료 분석이며 화면 조작 성공이나 틱 실시간 분석을 뜻하지 않는다. 기존 브라우저·서버를 재사용한다.
- 이미 받은 frame이나 읽기 전용 캐시를 사용한다. RSI·OBV·매물대 각각을 위해 재조회하지 않는다. 캐시를 현재 시세로 부르지 않는다.
- 누락된 이동평균·OBV·MACD 등은 프로젝트의 `results/dashboard/technical-indicators.js`의 `calculate(frame)` 결과를 사용한다. `sma20/60/120/200`, `obv`, `macd`, `signal`, `histogram`, `bollinger`, `donchian`을 제공한다. 화면 SMA20/60은 공급처 `frame.lines`에서 같은 봉의 `time`으로 찾은 값을 그대로 쓰고, 추가 계산의 출처는 구분한다. 평균선 배열의 시작 위치는 캔들 배열과 다를 수 있으므로 동일 index로 읽지 않는다.
- RSI·ATR·거래량 비율은 같은 frame의 `state[index]` 또는 실제 snapshot의 해당 값·evidence를 사용한다. 이 모듈에 없는 지표를 임의 공식으로 채우지 않는다.
- 과거 시점은 해당 index까지만 사용한다. 화면에서 선택한 EMA/WMA/밴드와 추가로 계산한 SMA를 같은 지표라고 표시하지 않는다. 화면 선택은 보조 데이터 확보를 위해 바꾸지 않는다.
- frame을 읽거나 추가 계산할 수 없으면 해당 항목은 `미확인` 또는 `자료 부족`으로 표시한다. 가격·전략 조건을 추정해서 채우지 않는다.

## 대화창 표시

먼저 최종 진입 상태와 핵심 이유를 1~2문장으로 설명한다. 날짜·공급처·조회 시각, 진행봉/확정봉 여부를 바로 다음에 표시한다. 장중 봉 가격은 `진행봉 가격`, 확정봉은 `확정봉 종가`로 구별한다. 틱 가격은 실제 quote의 시장 시각이 있을 때만 별도로 표시한다.

가격·지표 표에는 다음 데이터를 기본으로 포함한다. 값 옆에는 짧은 해석과 해당 봉 기준을 붙인다. 단위는 시장에 맞추고 작은 가격을 지나치게 반올림하지 않는다.

| 항목 | 표시 내용 |
|---|---|
| 가격 | 관찰봉 가격, 마지막 확정봉 종가와 각각의 날짜 |
| 이동평균 | SMA 20 / 60 / 120 / 200과 가격의 위·아래 관계. 화면의 별도 선택 지표가 있으면 이름을 명시 |
| RSI 14 | 실제 값·같은 주기 기준 |
| ATR 14 | 실제 값·가격 단위 |
| 거래량 | 관찰봉 거래량과 반환된 거래량 비율. 진행봉 거래량을 하루 전체와 직접 비교해 감소로 단정하지 않음 |
| OBV | 실제 누적값과 동일 이력·주기에서 5봉 전 대비 변화. 비교 가능한 값이 없으면 변화 미확인 |

OBV 비교는 동일 frame의 `obv[index] - obv[index-5]`를 사용한다. 양쪽 값과 그 사이 누적값이 유효할 때만 증가/감소를 설명하고 비교 기간을 명시한다. 누적값 단위는 거래량이며 순매수 금액·매집 확정을 뜻하지 않는다. 한 봉의 거래량이 평균·OBV를 크게 좌우하면 그 날짜와 영향도 짧게 설명한다.

지지·저항/진입 조건은 별도 짧은 표로 표시한다. 값의 역할을 `최근 저점`, `반등 고점`, `평균선`, `앱 돌파 기준`, `앱 무효 기준`, `앱 추격 상한`처럼 구분한다. 최종 entry와 선택 전략의 기준을 쓰며 만료된 구조 가격을 현재 진입 조건으로 사용하지 않는다. 저점 구조의 높은 저점과 두 저점 사이 반등 고점을 함께 보여주면 대기 이유를 읽기 쉽다. 수동 해석은 `추가 관찰 조건`으로 구별한다.

플래그·삼각수렴이 반환되면 종류·방향·형성 중/확정·돌파 기준만 요약한다. 현재 유효한 패턴이 없으면 `현재 유효 패턴 없음`이라고 표시한다. 미수집·조회 실패는 패턴 없음과 구별한다.

매물대가 계산 가능하면 `VolumeProfile.build(frame.candles, index)` 또는 snapshot의 기존 `volumeProfile`을 사용한다. 전체 계산 기간과 봉 수를 쓰고, 거래량 비중이 큰 최대 3개 bin의 가격 범위·비중·최대 여부를 표로 표시한다. 기존 bin을 좁히거나 새 경계를 만들지 않는다. 넓은 bin을 정밀 지지·저항으로 해석하지 않는다. 기본 표의 비중은 `share × 100`이다. 추가 시세 조회 없이 같은 frame으로 계산하며 일봉/월봉 매물대를 구분한다.

## 시각과 판단

- 표의 관찰봉 날짜와 진입 판단 `basis`가 다르면 각각 표시한다. 공급처 `fetchedAt`은 조회 시각이며 체결 시각이 아니다.
- 일치하지 않는 날짜·90초 초과·조회 실패 등은 원래 판단 보류 규칙을 유지한다. 날짜가 같은 것만으로 실시간이라고 하지 않는다.
- 주봉/월봉 라벨은 실제 마지막 거래일과 다를 수 있다. 진행 중 주·월의 미래 말일 라벨을 미래 시세로 설명하지 않는다.
- 지표 표를 채우기 위해 원래 진입 로직·봉 확정·데이터 신선도 검사를 바꾸지 않는다. 보조 지표가 좋아 보여도 최종 `blocked`, `wait`, `historical`을 매수 허가로 바꾸지 않는다.

대화창에는 핵심 표와 짧은 해석을 직접 넣는다. 앱이나 파일 링크만 보내지 않는다. 캔들·보조지표 그림을 요청받으면 실제 자료로 시각화하고 사용한 기간·출처·시각을 표시한다. 캡처가 필요하면 기존 단일 브라우저를 사용한다.
