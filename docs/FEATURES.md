# 기능과 판단 계약

## 추세·돌파

A는 SMA20/60 상향 교차, B는 RSI14의 30 상향 회복입니다. 돌파 항목은 직전 20봉 고점 돌파(C)와 추세·거래량 추가 확인(F) 중 선택합니다. F는 C를 포함하므로 독립된 두 확인으로 세지 않습니다. A/B는 원신호 이후 최대 3봉 동안 유지 조건·이탈·추격 제한·자료 시각 검사를 통과해야 진입 검토를 유지합니다. 원신호와 최종 판단은 별도입니다.

## 저점 매수

R은 지지 회복 뒤 확정 재시험과 반등 고점 돌파, H는 확정된 높은 저점 뒤 중간 고점 돌파를 기다립니다. 선택한 R/H 중 하나를 충족하면 검토합니다. ATR과 기준 가격은 신호 구조에 고정되며 무효선·기한·추격 상한을 검사합니다. 최초 신호봉이 이미 크게 오른 위험은 별도로 표시합니다. 거래량·OBV·가격 반응은 보조 증거이며 실제 매집을 증명하지 않습니다.

과거 판단은 당시 봉까지만 계산하고 현재 진입 안내와 구별합니다. 수동 선택한 과거 구조는 현재 최종 판단을 바꾸지 않습니다. `entry.family`, `settingsId`, `judgmentMode`로 전략군·설정·자료 상태를 확인합니다.

## 패턴·지표

저점 매수·플래그·삼각수렴은 주식 일봉, 코인 일봉/4시간봉, Yahoo Finance 주식 4시간봉을 지원합니다. 야후 주식 4시간봉은 거래일 개장 시각 기준으로 집계하며 장 마감·휴장·단축장·서머타임을 자료 누락과 구별합니다. `missingBarsBefore`가 실제 누락된 거래 봉 수를 기록하며, 누락 뒤에는 ATR·피벗·구조를 다시 준비합니다. 세션 연속성 정보가 없는 기존 주식 4시간봉 저장 자료는 새로 조회해야 합니다. 코인은 UTC 4시간 간격을 사용합니다. 최근 자료 기준 3개월 창에 구조 시작이 포함돼야 합니다. 일봉 규칙 v2, 4시간봉 v3이며 종가 돌파와 원천 자료 확정이 필요합니다. 수평 지지·저항은 주식 일봉과 Yahoo 주식 4시간봉을 지원하며 주기별 지정 가격과 기록을 분리합니다. 서버 감시는 주식 일봉을 사용합니다. R/H 알림 기능은 아닙니다.

차트에 20봉 저항과 10봉 지지, 지정 가격을 표시합니다. 최신 봉에 유효한 플래그·삼각수렴이 없으면 현재 구조 없음으로 표시합니다. 최근 3개월 창에서 확인된 과거 구조는 선택 목록에서 볼 수 있으며, 선택하면 해당 과거 봉으로 이동합니다. 이후 봉이나 미확정 봉의 구조는 과거 목록에 포함하지 않습니다.

SMA/EMA/WMA는 20/60/120/200봉입니다. 볼린저밴드는 20봉·표준편차 2배, 돈치안은 현재 봉 포함 20봉 범위입니다. OBV는 첫 봉 0에서 종가 방향에 따라 거래량을 누적하며 결측 뒤에는 중단합니다. 서로 다른 기간·주기의 OBV 절댓값을 비교하지 않습니다.

## 자료 시각

주식은 토스 API가 설정돼 있고 지원되는 종목이면 토스를 우선 사용하며, 미설정·미지원이면 Yahoo Finance를 사용합니다. 토스 오류 시에는 같은 공급처의 오류를 표시합니다. 토스가 미설정이면 한국 XKRX·미국 XNYS 정규장 캘린더를 사용합니다. 장 운영 metadata의 `source=exchange-calendar`, `scope=regular`로 구별하며, 토스는 통합 세션 기준입니다. 캘린더 조회 범위 밖이거나 의존성이 누락되면 운영 상태를 추정하지 않고 판단을 보류합니다.

Yahoo Finance 봉 검증에서 오류가 발견되면 마지막 오류 봉을 포함한 이전 구간을 제외하고 이후 정상 구간부터 모든 지표와 패턴을 다시 준비합니다. 가격 대체·휴장일 보간은 하지 않습니다. 일봉의 주봉·월봉도 동일한 정상 구간으로 집계합니다. `dataWarnings`에 오류 날짜·개수·제외한 봉 수·계산 시작일을 기록합니다. 오류 이후 80봉 미만이면 최신 조회를 실패 처리합니다.

장중 최신 캔들 판단의 앱 유효기간은 90초이며 공급처 지연 보증이 아닙니다. 진행 중인 봉은 잠정입니다. 봉 종료 후 30분이 지나고 실제 원천 재조회가 성공해야 확정합니다. 최신 봉 클릭은 현재 보기이며 실제 과거 확정 결과는 오늘의 조회 오류와 분리합니다. 저장 캐시의 latest는 최신 저장 자료이지 현재 실시간 가격이 아닙니다.

배포 내장 자료는 합성 예시입니다. 개인 기록·실제 계좌 원장·시세 조회 기록을 포함하지 않습니다. 전략의 수익성이나 패턴 오탐률을 보증하지 않습니다.

상단 검색·조회·갱신 버튼과 자료 안내는 고정된 공간에 표시합니다. 긴 안내는 마우스를 올리면 전체 내용을 확인할 수 있습니다.
